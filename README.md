# structured-corner-v2

BGS Corner General Trading LLC — Dubai. A fragrance-only UAE storefront:
house-blended attars, ouds, EDP sprays and bakhoor.

A standalone project. It does not continue or inherit from any earlier BGS
website — no code, no catalogue, no design is carried across.

**Status: design phase.** There is no application code here yet, and that is
deliberate.

See [UNDERSTANDING.md](UNDERSTANDING.md) for the working rules, the design
direction, what the brief requires, the build order and what is still open.
